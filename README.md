# 腾昇慧心碳控 · 碳排放管理平台原型

面向企业的碳排放管理平台高保真页面原型，覆盖组织碳排核算与产品碳足迹两条主线。纯静态实现，无需构建与后端，所有数据为演示数据。

## 快速开始

直接双击打开 `index.html` 即可。若需本地服务（推荐，避免部分浏览器对本地文件的限制）：

```bash
python3 -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/index.html
```

建议使用 Chrome / Edge / Safari 最新版，桌面端 1280px 以上宽度浏览。

## 页面结构

| 模块 | 页面 | 说明 |
| --- | --- | --- |
| 碳排核算 | 碳排总览 | 总量与绿能减碳指标、排放趋势、范围一/二/三构成、排放源排行 |
| 碳排核算 | 碳排报告 | A4 版式报告，支持预览 / 导出 / 打印 |
| 产品碳足迹 | 产品清单 | 产品碳足迹列表，支持新建、筛选、进入建模或计算 |
| 产品碳足迹 | 生命周期建模 | 按阶段维护生命周期清单，可切换产品、修改分配方法、新增清单项 |
| 产品碳足迹 | 碳足迹计算 | 切换产品查看单位产品碳足迹、计算结果与构成，可跳转报告 |
| 产品碳足迹 | 碳足迹报告 | 产品碳足迹报告，支持预览 / 导出 / 打印 |
| 基础管理 | 减碳管理 | 减碳目标、措施与进度跟踪 |

导航中的「排放因子库」「组织与边界」为占位菜单，点击提示即将上线。

## 主要交互

- **产品清单 → 生命周期建模 / 碳足迹计算**：点击列表中的产品，目标页自动选中该产品
- **新建产品碳足迹**：在产品清单弹窗内创建，新建产品默认「待核算」，完成建模后才会出现在计算页
- **生命周期建模**：产品下拉切换、分配方法（按质量 / 产值 / 产量）可改、新增清单项实时计入合计
- **查看碳足迹**：从建模页一键带产品跳转计算页；未完成建模的产品会提示不可查看
- **报告预览**：统一 A4 预览弹窗，支持下载与浏览器打印，打印时自动隐藏侧栏与配置区

## 目录结构

```
.
├── index.html          # 页面结构与内联 SVG 图标
├── assets/
│   ├── style.css       # 设计变量、布局与组件样式、打印样式
│   └── app.js          # 视图切换、产品数据、图表绘制与全部交互
└── README.md
```

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无打包步骤
- 图表与仪表为内联 SVG / Canvas 绘制，不依赖外部 CDN
- 产品数据集中在 `assets/app.js` 的 `PCF_PRODUCTS`，便于继续扩展
- 静态资源引用带版本号（如 `app.js?v=...`），更新后刷新即可生效，必要时强刷 `Ctrl + Shift + R`

## 说明

原型仅用于方案演示与评审，数值、单位与报告内容均为模拟数据，不代表真实核算结果。
